# 📊 Customer Segmentation Dashboard using Power BI

An interactive **Power BI Dashboard** that analyzes customer demographics and spending behavior to uncover valuable business insights. This project demonstrates data visualization, dashboard design, and business intelligence techniques using Power BI.

## 🎯 Project Objective

The objective of this project is to analyze customer data and provide meaningful insights through an interactive Power BI dashboard. It helps businesses understand customer behavior and supports better decision-making.

---

## ✨ Features

* Interactive Dashboard
* KPI Cards
* Customer Demographics Analysis
* Age Distribution
* Gender Analysis
* Annual Income Analysis
* Spending Score Analysis
* Interactive Slicers & Filters

---

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Microsoft Excel / CSV

---

## 📂 Dataset

**Mall Customers Dataset**

**Columns**

* Customer ID
* Gender
* Age
* Annual Income (k$)
* Spending Score (1–100)

## 🚀 How to Use

1. Clone or download this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. Explore the dashboard using the available filters and slicers.
